# B:FREE

### Barrier Free, Be Free.

**서울 중구 배리어프리 편의시설 지도**
경사로 · 엘리베이터 · 장애인 화장실 · 점자블록 · 주차공간 · 수어·자막 정보를 방문 전에 한눈에

## Overview

갈 수 있는 곳인지, 가 보기 전에 알 수 있어야 합니다.

휠체어 이용자, 시각·청각장애인, 고령자, 유아차 이용자에게는 목적지에 경사로·엘리베이터·장애인 화장실이 있는지가 외출 여부를 결정합니다. 그러나 이 정보는 기관별 홈페이지와 공공데이터에 흩어져 있어, 이용자가 직접 찾아 조합해야 합니다.

**B:FREE는 흩어진 접근성 정보를 하나의 표준 구조로 정리하고, 이용자 유형에 맞춰 필요한 시설만 즉시 보여주는 배리어프리 지도입니다.**
설치·로그인·회원가입 없이, 링크 하나로 바로 사용할 수 있습니다.

| 지표 | 내용 |
|---|---|
| 서비스 지역 | 서울특별시 중구 (15개 행정동) |
| 수록 시설 | **30곳** — 관광지·문화시설·공연장·미술관·박물관·도서관·공원·관광안내소·음식점·지하철역 14곳 |
| 편의시설 항목 | **6종 표준 분류** — 경사로 · 엘리베이터 · 점자블록 · 장애인 화장실 · 주차공간 · 수어·자막 |
| 그 외 지역 | 전국 시도·시군구, 서울 자치구 지도 표시 + '서비스 준비 중' 안내 |

## Key Features

### 1. 이용자 중심 탐색
- **유형별 빠른 선택** — 한 번의 선택으로 필요한 조건이 자동 적용됩니다.

  | 유형 | 적용 조건 |
  |---|---|
  | 휠체어 이용자 | 경사로 + 엘리베이터 + 장애인 화장실 |
  | 시각장애인 | 점자블록 · 점자 안내 |
  | 청각장애인 | 수어·자막 안내 |
  | 모든 시설 | 조건 해제, 전체 보기 |

- **개별 필터 조합** — 6종 편의시설을 자유롭게 조합(AND 조건)해 원하는 곳만 남깁니다.
- **통합 검색** — 시설·역·동 이름으로 검색합니다. 결과가 하나면 지도에서 바로 상세 정보를 열고, 서비스 지역 밖(다른 구·시군구·시도)을 검색하면 해당 위치로 이동해 준비 중임을 안내합니다.
- **즐겨찾기** — 자주 가는 곳을 저장하고 '즐겨찾기만 보기'로 모아 봅니다. 브라우저에만 저장되며 서버로 전송되지 않습니다.

### 2. 두 가지 보기 방식
- **목록 보기 (기본)** — 큰 카드에 갖춘 편의시설, 운영시간, 이용 시 주의사항을 함께 표시합니다. 카드를 누르면 지도 상세로 이어집니다.
- **지도 보기** — 핀의 숫자는 그 시설이 갖춘 편의시설 개수입니다. 조건에 맞는 곳은 강조되고, 맞지 않는 곳은 흐려집니다.

### 3. 상세 정보
- 편의시설 6종의 **있음 / 정보 없음** 표시
- 운영시간, 현장 메모(예: "한옥 건물 진입은 단차로 어려움")
- **가장 가까운 지하철역**과 직선거리 자동 계산
- **음성으로 듣기** — 시설명·주소·운영시간·편의시설을 한국어 음성으로 읽어 줍니다.
- **카카오맵 길찾기** — 버튼 하나로 목적지가 지정된 길찾기 화면으로 이동합니다.

### 4. 자체 구현 SVG 지도
- **전국 → 서울 → 중구** 3단계 확대, 단계 이동 버튼과 부드러운 확대 애니메이션
- 마우스 휠·드래그, 모바일 핀치 줌 지원
- 확대 수준에 따라 도로·철도·하천·역·지명 표시를 단계적으로 바꾸는 레벨 오브 디테일(LOD) 렌더링
- 전국 지도는 0.5도 단위 타일로 나눠 **화면에 보이는 영역만 그리도록** 최적화
- 서비스 지역(중구)만 밝게, 그 외 지역은 어둡게 처리해 범위를 직관적으로 표시
- 지하철 노선별 공식 색상 구분과 노선 범례

## Accessibility by Design

접근성 서비스는 그 자체가 접근 가능해야 합니다. B:FREE는 기능 이전에 다음 원칙을 기준으로 설계했습니다.

| 원칙 | 구현 |
|---|---|
| 색에만 의존하지 않기 | 핀에 숫자를 함께 표시하고, 상세 정보는 ✓ 표시와 텍스트로 구분 |
| 키보드만으로 사용 | 본문 바로가기 링크, 모든 버튼과 지도 핀에 Tab·Enter·Space 지원, 뚜렷한 포커스 표시 |
| 스크린리더 지원 | 버튼 상태(aria-pressed), 결과 수 실시간 안내(aria-live), 지도 핀 레이블, 목록과 지도의 동일한 정보 제공 |
| 큰 글씨 모드 | 한 번의 전환으로 화면 전체 글자 크기 확대, 설정 자동 저장 |
| 충분한 터치 영역 | 주요 버튼 높이 44px 이상 |
| 눈의 피로 고려 | 시스템 다크 모드 자동 대응 |
| 움직임 최소화 | 시스템의 '동작 줄이기' 설정 시 애니메이션 생략 |
| 반응형 | 데스크톱(좌측 패널 + 지도)과 모바일(지도 + 하단 상세 창) 레이아웃 분리 |

## Architecture

```
index.html  (단일 파일, 설치·빌드 불필요)
├── Data layer      시설 30곳 + 지도 기하 데이터 (JSON 내장)
│                   └ 시설 스키마: name · category · address · lat/lng
│                                  · features[6종] · hours · note
├── Render layer    SVG 레이어 12개 (시도 → 시군구 → 자치구 → 중구 → 도로·철도
│                   → 하천 → 경계 → 라벨 → 역 → 핀)
├── Interaction     확대·이동, 필터·검색·즐겨찾기 상태 관리
└── Services        Web Speech API(음성 안내) · LocalStorage(즐겨찾기·글자 크기)
                    · 카카오맵 길찾기 URL
```

- **Zero dependency** — 프레임워크·라이브러리·지도 API 키 없이 순수 HTML·CSS·JavaScript로 동작합니다. (글꼴만 웹폰트 CDN 사용)
- **Offline-friendly** — 지도와 데이터가 파일 안에 포함되어 있어 외부 지도 서버 없이 렌더링됩니다.
- **Scalable schema** — 모든 시설을 6종 표준 항목으로 기록하므로, 데이터만 추가하면 다른 구와 서울 전역으로 확장할 수 있습니다.

### Tech Stack

| 구분 | 기술 |
|---|---|
| Frontend | HTML5, CSS3 (Custom Properties, Grid, `color-mix`), Vanilla JavaScript (ES2020+) |
| 지도 | SVG 기반 자체 지도 엔진 (OpenStreetMap 데이터, 통계청 행정경계) |
| 브라우저 API | Web Speech API, LocalStorage, Pointer Events, ResizeObserver |
| 외부 연동 | 카카오맵 길찾기 링크 |
| 배포 | GitHub Pages |

## Getting Started

별도 설치 없이 실행됩니다.

1. **[서비스 바로가기](https://25730010sewu.github.io/BFREE/)** 로 접속하거나,
2. 저장소의 `index.html` 파일을 브라우저로 엽니다.

> 권장 환경: 최신 버전의 Chrome, Edge, Safari, Firefox
> 음성 안내는 Web Speech API를 지원하는 브라우저에서 표시됩니다.
