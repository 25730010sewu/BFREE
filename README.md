# B:FREE — 배리어프리 편의시설 지도

> **Barrier Free, Be Free.**
> 서울 중구의 경사로·엘리베이터·장애인 화장실·점자블록 등 배리어프리 편의시설을 한눈에 찾을 수 있는 웹서비스


🔗 **서비스 바로가기:** https://25730010sewu.github.io/BFREE/

---

## 기획 의도

장애인, 고령자, 유아차 이용자에게는 가려는 장소에 경사로나 엘리베이터, 장애인 화장실이 있는지가 외출을 결정하는 중요한 정보입니다.
하지만 이런 정보는 여러 곳에 흩어져 있어 미리 확인하기 어렵습니다.
**B:FREE**는 이 정보를 한곳에 모아 누구나 쉽게 찾아볼 수 있도록 만든 배리어프리 편의시설 지도입니다.

## 서비스 범위

| 구분 | 내용 |
|---|---|
| 현재 서비스 지역 | 서울특별시 중구 (관광지·문화시설·관광안내소·지하철역 등 30곳) |
| 그 외 지역 | 전국 지도 표시, '서비스 준비 중' 안내 |

## 주요 기능

- **유형별 빠른 선택:** 휠체어 이용자, 시각장애인, 청각장애인 중 하나만 누르면 필요한 시설만 표시
- **목록 보기 / 지도 보기:** 시설 정보를 카드 목록으로 보거나 지도에서 위치 확인
- **검색:** 시설 이름, 역 이름, 동 이름으로 검색
- **상세 정보:** 편의시설 6종(경사로, 엘리베이터, 점자블록, 장애인 화장실, 주차공간, 수어·자막), 운영시간, 가까운 역 안내
- **카카오맵 길찾기 연결:** 버튼 하나로 카카오맵 길찾기 이동
- **접근성 기능:** 음성 안내(시설 정보 읽어 주기), 큰 글씨 모드
- **즐겨찾기:** 자주 찾는 시설 저장(브라우저 LocalStorage)
- **지도:** 전국 → 서울 → 중구 단계별 보기, 지하철 노선 색상 구분

## 실행 방법

별도 설치 없이 실행됩니다.

1. 위의 **서비스 바로가기** 링크로 접속하거나
2. 저장소의 `index.html` 파일을 브라우저로 열면 됩니다.
